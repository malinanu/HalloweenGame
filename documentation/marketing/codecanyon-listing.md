# Spooky Maze Runner — Halloween HTML5 Maze Game (Re-skinnable, with Leaderboards)

**Category:** CodeCanyon → HTML5 → Games
**Tags:** halloween, html5 game, maze game, arcade, three.js, 3d game, promo game, brand game, leaderboard, mobile game, reskin, campaign

---

Collect the treats, dodge the skeletons, survive the haunted maze!

**Spooky Maze Runner** is a 3D Halloween maze game for phones, tablets and desktops. Players
run through a haunted dungeon collecting the sponsor's products while five skeleton monsters
hunt them down. A new maze every round, 60-second rounds, three lives and an online
leaderboard make it perfect for **brand promotions, seasonal campaigns, events and websites**.

### Re-skin it in minutes
One JSON file changes the game name, logo, colours, the five collectible products (with your
own product photos), their 3D shape (**bag, can, box, coin or gift**) and the prize text.
Three ready-made skins are included: *Spooky Maze Runner* (treat bags), *Fizz Fright Night*
(drinks) and *Reward Rush* (loyalty coins).

### Features
- Real-time 3D graphics (three.js / WebGL) — no plugins, no build step
- Works on phones, tablets and desktops; portrait and landscape layouts (taller mazes on tall phones)
- Swipe-anywhere controls on mobile, arrow keys / WASD on desktop
- A new random maze every round, with escape loops
- Five monsters with their own speed and chasing behaviour
- Built-in tutorial, countdown, pause, sound toggle, vibration, fullscreen
- Skill-based scoring: combos, speed bonus, near misses, full sets, lives and survival bonus
- **Optional Node.js leaderboard server** (zero dependencies): daily / weekly / all-time boards,
  one entry per player, cheat checks, **CSV export of winners**
- Optional mobile-number entry for prize campaigns (Sri Lankan or international formats)
- Works without a server too (local high scores)
- Several branded versions on one server, each with its own leaderboard
- Fully offline: fonts, 3D models and effects bundled; synthesized sound — no external requests
- Automatic low-graphics mode for older devices
- Detailed HTML documentation

### What's included
- Complete source code (HTML, CSS, JavaScript ES modules)
- Leaderboard server (`server.js`) and PM2 config
- 3 skins, 3D models, effects, fonts
- Documentation

### Requirements
- Any modern browser with WebGL
- For shared leaderboards: Node.js 18+ (any Node host, VPS, CloudPanel, Render, Railway…)
- For static hosting: any web server
