Collect the treats, dodge the skeletons, survive the haunted maze!

**Spooky Maze Runner** is a 3D Halloween maze game for phones, tablets and desktops. Players run through a
haunted dungeon collecting the sponsor's products while five skeleton monsters hunt them down. A new maze
every round, 60-second rounds, three lives and a leaderboard at the end.

### Highlights
- **Re-skin from one JSON file:** game name, logo, colours, five collectible products (with real product photos),
  their 3D shape (bag, can, box, coin, gift) and prize text. 3 skins included.
- **Ready-made platform builds:** YouTube Playables (SDK integrated, cloud save, score reporting),
  CrazyGames and GameDistribution (ads between rounds) — one command each.
- **Optional Node.js leaderboard server** (zero dependencies): daily/weekly/all-time, one entry per player,
  cheat checks, CSV export of winners. Works without a server too.
- Real-time 3D (three.js), swipe controls, a new maze every round, tutorial, vibration, fullscreen, auto low-graphics mode.
- Fully offline: no external requests; fonts, 3D models and effects included; synthesized sound.
- HTML documentation.

### Included
Complete source (HTML, CSS, JavaScript ES modules), leaderboard server, build tool, 3 skins, assets, documentation.
